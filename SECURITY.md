# Security Policy

## Supported Versions

Only CI/CD templates and configurations maintained on `main` are supported.

| Version | Supported          |
|:--------|:------------------:|
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Security Issue

If you discover a vulnerability or credential leakage flaw in these GitLab CI pipelines:

1. **Do not open public GitHub or GitLab issues**.
2. Email maintainer **Tayyab Masood** at **tayyabmasood911@gmail.com** with the subject `[SECURITY] GitLab CI Pipeline Flaw`.
3. Provide details of the job definition, variable exposure risk, or container isolation flaw.

All reports will be evaluated within 24 hours.
